Which axes get normalized: BatchNorm, LayerNorm, InstanceNorm, GroupNorm, RMSNorm

Every normalization layer subtracts a mean and divides by a standard deviation (RMSNorm skips the mean). They differ only in which numbers share one mean. The block is a batch of activations, one small cube per number: N examples, C channels, and each channel’s H×W feature map unrolled into one column. The grid beside it shows the same numbers the way a convolutional network holds them, one little H×W map per example and channel. Click a cell in either to light up the cells it is normalized with; drag to turn the block.
