LSTMs, highways, ResNets: one additive path, through time or through depth

A residual block looks a lot like an LSTM cell, and that is no accident. Both keep a state that is updated by adding to it, so the gradient has a path back that is not multiplied by a weight matrix at every step. An LSTM runs that path through time; a ResNet runs it through depth. Below, the gradient reaching step 0 from step T, for four update rules.

The four rules, with the factor each multiplies the gradient by per step along its best path: a plain recurrence or layer, ht = φ(W ht−1), multiplies by WT and the activation’s slope every step, so unless that product is exactly 1 the gradient shrinks or grows exponentially (Hochreiter 1991; Bengio et al. 1994). The LSTM (Hochreiter & Schmidhuber 1997) adds a cell state ct = f·ct−1 + i·g: along the cell, the gradient is multiplied only by the forget gate f, and with f = 1 (the original “constant error carousel”; the forget gate came in Gers et al. 2000) it passes unchanged. Highway networks (Srivastava et al. 2015, months before ResNet) took the same gated, additive idea from time to depth: y = t·H(x) + (1 − t)·x, carrying a fraction 1 − t of x straight through. ResNet drops the gate: y = x + F(x), a highway that is always fully open, so the factor along the shortcut is exactly 1 and the branch only adds corrections (the rate here assumes a branch whose Jacobian contributes a small ±5% per step on average). So the idea was not new in 2015; what was new was applying the always-open version to very deep feedforward networks, alongside BatchNorm and GPUs, and showing that it beat everything on ImageNet. He et al. also point out that a highway layer whose gate closes stops being residual, while their shortcut is never closed.
