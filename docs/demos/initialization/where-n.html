Where the n comes from: a matrix product of random numbers

Every entry below is a random variable, drawn as its density with one sample marked on it. A layer multiplies an m×n weight matrix by an n-vector, so each output adds up n random products, and variances add. On the way back the gradient goes through WT, so each input's gradient adds up m of them instead.

n inputs 6 m outputs 3 weight std σw 1.00
Weights are either Gaussian, w ~ N(0, σw²), or uniform as Glorot & Bengio drew them, on [−a, a] with a = √3·σw so the variance is the same (see why a²/3); the inputs x and the upstream gradients ∂L/∂h are N(0, 1). Every cell uses the same horizontal scale, −4 to 4, so a wider curve means a bigger variance; each curve is drawn as a fine histogram would show it, scaled to its own peak. Products are not normal: w·x has variance σw²·1 either way, but a sharp peak at 0. With Gaussian w its density is K0(|z|/σw)/(πσw), a Bessel function with exponential tails; with uniform w it is E1(z²/2a²)/(2a√(2π)), an exponential integral whose tails fall off like a Gaussian's, since |w| ≤ a. Both are drawn exactly. Sums become normal: adding several independent products gives a curve close to a Gaussian (the central limit theorem), with variance the sum of theirs. Forward, hi = Σj wijxj adds n products. Backward, the chain rule gives ∂L/∂xj = Σi wij∂L/∂hi: column j of W, which is row j of WT, so it adds m products. The dashed curve on each result is N(0, 1), the spread that went in.

Stacking layers: the n·Var(W) factor compounds

n (fan-in) 64
Inputs xi ~ N(0, 1). The standard rule sets a scale of 1/√n, and what that does depends on how the scale is used. Used as the half-width of a uniform on [−1/√n, 1/√n], as in the paper, it gives Var(W) = a²/3 = 1/(3n) (see standard vs. normalized init for the a²/3), so n·Var(W) = 1/3. Used as the standard deviation of a Gaussian (LeCun's 1998 advice), it gives Var(W) = 1/n, and the 1/3 is gone. Glorot for a layer with nin = nout = n targets Var(W) = 2/(n+n) = 1/n whichever distribution draws it: half-width √(3/n) for uniform, std 1/√n for Gaussian. Only the variance matters, not the shape of the distribution. The dashed line on the right is the prediction (n·Var(W))L, which assumes tanh(h) ≈ h; the bars push 400 inputs through real width-n tanh layers, drawing fresh weights at every layer. Even at n·Var(W) = 1, the bars fall below the dashed line, steeply at first and then slowly: tanh flattens values beyond about ±0.5, so Var(tanh h) < Var(h), and a unit-variance input keeps only about 40% of its variance through the first tanh. The gap closes once the signal is small enough that tanh(h) ≈ h, which is why the decline slows instead of compounding by a fixed factor. The variance page has the rules behind all of this, and forward vs. backward has Glorot's compromise between 1/n and 1/m.
