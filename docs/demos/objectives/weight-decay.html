4. What nobody asked: L2 inside Adam is not weight decay

For plain gradient descent, adding the penalty to the loss and shrinking the weights are the same thing. Inside Adam they are not, because Adam divides every gradient, including the penalty’s, by that weight’s recent gradient size. Two weights start at 1. Their loss gradients flip sign every step and average to zero, so only the regularizer moves them: one gets big gradients (±10), one tiny ones (±0.001).
