Batch size, learning rate, and gradient noise: the minibatch is a noisy estimate

Every SGD step uses the average gradient of B examples instead of all N. That estimate is noisy, and the noise sets how SGD behaves: how tightly it settles, why the learning rate should grow with the batch, and which minimum it ends up in.
