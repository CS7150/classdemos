    Backprop through y = Ax

    Why the backward pass multiplies by Aᵀ. The forward product drawn as wires, then run in reverse: the gradient g deals one entry to each row of A, the scaled rows add up to ∂L/∂x = Aᵀg, and the product rule on each wire gives the weight gradient ∂L/∂A = g xᵀ. The left panel replays the matrix × vector animation on Aᵀ and g; click any wire to see the product rule on it.
