Conditional flows add up to a marginal flow: crossing lines, one smooth field

Flow matching trains a velocity field to carry noise (left edge) to data (right edge). Say the data are a few single points, Diracs. For one target alone the path is easy: a straight line to it. Drag the diamonds, change their probabilities with the sliders, and compare what happens when every target has its own line (left) with the single field a network has to learn (right).
