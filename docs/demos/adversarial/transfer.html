Adversarial examples transfer: made for one network, they fool the others

The paper’s most surprising finding: an adversarial example found with one network’s gradients is often misread by a different network, one with another size, other regularization, even one trained on a disjoint half of the training set that shares no weights and no training images. Below, each row makes adversarial examples for one network (with the paper’s search, live), and each column tests them on another.

The networks. All are trained with the same code on MNIST digits (12,000 of them here, against the paper’s 60,000): two sigmoid networks of different width, a softmax classifier with no hidden layer and its own weight decay (the paper’s FC10), and three networks of the same size trained on halves of the data, two on the first half from different random starts and one on the second half, the paper’s P1 and P2. Each row runs the paper’s search (projected gradient on c·|r|² + loss for a random wrong target, with a line search on c) for that row’s network only. A cell is the fraction of those examples the column’s network gets wrong, so the diagonal is 100% by construction. The last row adds Gaussian noise of the same size to the same digits. Magnify scales every change up, as the paper did in Table 4 (by 40%) to show that a slightly larger change transfers much more often.
Why would they transfer? This is the question most of you asked, and the paper does not answer it. Three ideas since. (1) Similar functions: networks trained on the same task end up computing similar functions, so their gradients point in similar directions; the transfer is strongest between networks of the same shape and weakest to the softmax model, whose decision rule is simplest. (2) Linearity: in high dimensions, a change aligned with what any reasonable model weighs (the strokes and edges that separate the digits) adds up for all of them (tiny crafted vs. large random). (3) Features, not bugs: Ilyas et al. 2019 argue the perturbations exploit patterns that genuinely predict the label in the data, but which humans do not use; every model is rewarded for using them, so every model is fooled by them. That fits the disjoint-half result: the second half of the data has the same patterns as the first.
