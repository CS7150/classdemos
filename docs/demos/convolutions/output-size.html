How big is the output?: count where the window can start

The lecture’s question: a 3×3 filter on a 7×7 input, how big is the output? Every output is one place the window fits, so count the places. Press Play, then change the kernel, stride and padding.

A stack of layers: each one shrinks what it is given

Each activation drawn as a block, channels × height × width, with the front face to scale. Between blocks, one filter: K×K across the full depth of its input, making one number of the next block. Drag a filter to scan it across its input and watch which output it makes; the filters before and after it follow when they must, so each one always reads the cell the one before it made. drag anywhere else to turn the picture.
